# 2026-11-19_home-bp-app-flag

**Synthetic example.** Does an app's "Stage 1 Hypertension" label hold up?

| File | What | Read |
|---|---|---|
| `conclusion.md` | The one page the owner reads | 1st |
| `brief.md` | The owner's brief, with safety questions and hypothesis | 2nd |
| `plan.md` | Phases 0 to 3 and the owner overview | 3rd |
| `reanalysis.md` | How to reach the same numbers, and how the plan changed after the first result | 4th |
| `review.md` | The latest independent review | 5th |
| `analysis.py` | The script; `--check` reruns and compares | |

Data output: `example/data-folder/analyses/2026-11-19_home-bp-app-flag/results.csv`.
Earlier versions of these files, and earlier review rounds, are in git history;
`reanalysis.md` § 9 lists what changed and in which commit.
