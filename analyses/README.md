# analyses

One folder per analysis, named `YYYY-MM-DD_<topic>/` after the day it started. Contents
and rules: [METHOD.md § 8](../METHOD.md#8-the-analysis-folder). A new question is a new
folder; a corrected answer is a corrected folder, with the history in git.

Data outputs never go here; they go to `<data_path>/analyses/<same name>/`
([DATA.md § 6](../DATA.md#6-where-analysis-files-go)).
