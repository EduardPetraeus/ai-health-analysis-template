# knowledge

General knowledge about health topics, with sources: how a marker works, what a guideline
says, how a measurement is done. **Never findings about the owner**; those live in
analyses and `status/`.

One file per topic, lowercase with hyphens (`blood-pressure-measurement.md`). Every claim
has a source with a link, following the source order in
[METHOD.md § 6](../METHOD.md#6-semantics-before-numbers). Each file states when it was
last checked, because guidelines change.
