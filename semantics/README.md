# semantics

What the owner's data mean. Read [CONCEPTS.md](CONCEPTS.md) first; the rules are in
[METHOD.md § 6](../METHOD.md#6-semantics-before-numbers).

| Path | Holds |
|---|---|
| `CONCEPTS.md` | The words used here and where each kind of knowledge lives |
| `sources/` | One folder per data source: the source file and one file per object |
| `ontology/` | Concepts across sources, one file per domain |
| `metrics/` | Formulas computed from documented fields |

For a filled in example, see [`example/semantics/`](../example/semantics/README.md).
