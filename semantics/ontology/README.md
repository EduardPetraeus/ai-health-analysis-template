# ontology

Concepts that exist independently of any provider, one file per domain from
[`templates/ontology.md`](../../templates/ontology.md)
(`cardiovascular.md`, `sleep.md`, `metabolism.md`). Each concept has an `id`, a
definition with a source, its unit, and which source fields carry it.

Add a concept when a second source carries the same thing, or when a single source's
field name is misleading. Until then, the object file is enough.
